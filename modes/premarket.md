# Mode: premarket — 盘前分析(9:12 ET)

**目标:定今日方案。** 不是"看一眼行情",而是产出一份当天可执行的作战计划,
让后面 10:33 / 13:03 / 15:37 三个检查点有明确的输入,不用从零开始想。

**为什么盘前常规不下单:** 盘前**市价单**无法成交(订单类型与时段不匹配,
见 `_mechanics.md` §1),不是策略禁止。若判断确有依据,两条路都开着:
① 用合格标的的**限价单**在延长时段执行(先 `get_equity_tradability` 核实);
② 把单子安排到正常时段执行。两者都要过 `preflight.py`。

---

## Step 0 — 环境与时间自检

1. `date` + `TZ=America/New_York date`,核对实际 ET 时间 vs 计划的 9:12。
   迟到按 `_mechanics.md` §5 的分级处置。
2. 跑 `make doctor`,重点看:
   - `caffeinate` 是否在跑(不在则拉起)、电源状态
   - 今天是否交易日 / 是否半日市
   - `config/profile.toml` 是否就位
3. **调度修复(best-effort)**:核对 10:33 / 13:03 / 15:37 / 16:06 四个检查点的 cron 是否存活,
   缺失立即重建(重建时把时间自检写进每条 prompt)。
4. `get_equity_orders`(当日 + 前一日)核对是否有意外成交或未取消的挂单。

## Step 1 — 并行拉数据

一次并行发起,不要串行等:

- `get_portfolio` — 总值、现金、buying power
- `get_equity_positions` — 每个标的股数、成本价、当前市值
- `get_equity_quotes` — 全部持仓 + 基准 `SMH` `QQQ` `SPY` `TLT` `VIX`
- WebSearch — 隔夜/盘前:期货、亚欧股市、重大新闻、盘前异动榜
- `get_earnings_calendar` — 今日及未来 3 日财报(用于算 blackout 窗口)

归档快照(供复盘与仪表盘用):

```bash
echo '<json>' | python3 scripts/snapshot.py --stdin --checkpoint 09:12
```

payload **必须包含 `normalized` 块**(`total_value` / `cash` / `buying_power` /
`equity_value` / `positions[]`),否则 `make dashboard` 读不到 ——
券商原始字段名不稳定,脚本不猜。规范见 `docs/DATA_CONTRACT.md` §4。

## Step 2 — 今日约束清单(先划禁区,再找机会)

按顺序确认,把不能动的标的先排除:

| 检查 | 判定 | 结果 |
|---|---|---|
| 今天是交易日? | `make trading-day` | 否 → 停,只汇报 |
| 是否半日市? | 提前收盘影响尾盘窗口 | 是 → 把 15:37 提到收盘前 23 分钟 |
| 哪些标的在自身二元催化窗口内? | 财报日历 + `catalyst.blackout_hours` | 列出 → 按 `_strategy.md` 的暂停规则处理 |
| 今天有宏观数据/FOMC? | 经济日历 | 有 → 数据落地前不抄底 |
| 今天是周五 / 长周末前? | 你的规则里是否有例外条款 | 有 → 按 `_strategy.md` 处理 |
| 是否长周末前最后一个交易日? | 假期日历 | 是 → 考虑减仓过节 |
| 卖出资金 T+1 是否已结算? | 前一日有卖出则算 | 未结算 → 今日可用 BP 打折 |

## Step 3 — 持仓体检

对每个持仓输出一行,**必须包含**:

```
{标的} | 现价 vs 成本({%}) | 占股票市值({%}) | 距关键触发线 | 催化窗口内? | 今日倾向
```

同时给组合级:

- 总值 / 现金 / **BP 占总值 %**(vs `cash.bp_target_pct` 目标,超了要说明部署计划)
- 组合浮盈亏 %
- **集中度**:最大单一标的占股票市值 %(vs `position.max_single_pct`)
- **相关性缺口**:哪些仓位其实是同一个风险敞口(`_strategy.md` 分散一节)

## Step 4 — 今日方案(核心产出)

### 4.1 大盘与利率预判

- 期货方向 + 隔夜驱动(宏观 / 财报 / 地缘 / 利率)
- 你在 `_strategy.md` 里定义的宏观确认指标及其**幅度门槛**(温和波动不构成确认)
- 今日 risk-on / risk-off / 分化

### 4.2 候选清单(给 10:33 的输入)

**这是盘前最有价值的产出。** 每个候选必须写全三件事,缺一不可:

```
候选:{标的}  方向:{加仓 / 新开仓 / 减仓}
理由:{具体催化或技术依据}
触发参考:{价格或条件,整数位偏移半档 —— `_mechanics.md` §6}
尺寸:{trade.size_std 或 size_max,并注明占该仓位当前市值 %}
准入判定:{按 `_strategy.md` 建仓一节的判定标准,写明结论与依据}
```

找候选时的硬约束:

- **不要只在已持仓标的里循环**(`_strategy.md` 分散一节)。主动扫更广的候选池。
- 部署优先级按 `_strategy.md` 里你定义的顺序。
- 新标的准入门槛按 `_strategy.md` 建仓一节,不因'要部署现金'而放宽。

### 4.3 防守预案

- 每个持仓的**破位触发线**(偏移整数半档)
- **确认条件**:按 `_strategy.md` 定义的组合条件(单一条件成立通常不足以触发)
- 触发后的动作与尺寸(先算占该仓位市值 %,不要直接套标准尺寸)

### 4.4 今日"不做什么"

明确写出来,防止盘中临时冲动:

- blackout 名单(催化窗口内的标的)
- 已判定不符合准入条件、今天不追的标的
- 连续 3+ 检查点等回踩未达标、**已判失效**需要换标的或放宽条件的候选

## Step 5 — 输出格式

```markdown
## 盘前分析 · {YYYY-MM-DD}(ET {实际时间})

**自检**:交易日 ✅ / 半日市 ❌ / caffeinate ✅ / 调度 4/4 存活 / 昨日无意外成交

### 一、隔夜与盘前
{3-5 句:期货、驱动、TLT、risk 姿态}

### 二、持仓体检
{每持仓一行 + 组合级指标}

### 三、今日约束
{blackout 名单 / 宏观事件 / 周五或假期例外 / T+1 结算}

### 四、候选清单
{每候选:方向 / 理由 / 触发参考 / 尺寸 / 准入判定}

### 五、防守预案
{触发线 + 确认条件 + 动作}

### 六、今日不做什么
{明确列出}

**给 10:33 的一句话**:{今天最该干的一件事}

*以上为分析,不构成投资建议。*
```

## 收尾

盘前分析**不写 `data/journal.md`**(那是 16:06 `journal` mode 的职责)。
如果盘前就产生了实际下单,才在下单后按 `modes/trade.md` 记入 `data/trades.tsv`。
