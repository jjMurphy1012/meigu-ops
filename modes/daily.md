# Mode: daily — 美股收盘日报

**角色:** 专业美股市场日报分析师 + 宏观策略分析师。

**骨架完全由 `config/watchlist.toml` 驱动** —— 指数、板块、主题、技术面标的、
分组、风险维度全部来自用户配置。本仓库不预设任何研究范围。

**目标:** 让读者在 5 分钟内理解——昨夜发生了什么、市场为什么涨跌、资金在买什么卖什么、
哪些板块/个股异动、接下来该关注什么风险和机会。

**产出:** `reports/YYYY-MM-DD.md`(已 gitignore)。

---

## 执行流程

### Step 1 — 生成骨架

```bash
make report          # 等价于 python3 scripts/new_report.py
```

脚本会:确认是交易日 → 从 `templates/daily-report.md` 生成 `reports/{日期}.md` →
写入日期、编号、上一交易日引用、`config/watchlist.toml` 里的关注股清单。

**不要手写文件名或手算日期。** 遇到长周末、假期、半日市,脚本比人可靠。

### Step 2 — 取数(数据来源优先级)

| 优先级 | 来源 |
|---|---|
| 1 | 券商实时接口:`get_index_quotes` / `get_equity_quotes` / `get_equity_historicals` / `get_equity_technical_indicators` / `get_earnings_calendar` |
| 2 | 权威财经媒体:CNBC、Reuters、Bloomberg、MarketWatch、WSJ、Yahoo Finance、Investing |
| 3 | 数据/工具站:Barchart、Koyfin、TradingView、Finviz、Nasdaq、FactSet |
| 4 | 一手来源:公司 IR、SEC 文件、CME FedWatch、FRED、美国财政部、EIA |

**硬规则(`AGENTS.md` 铁律 #1):**

- **不编造任何数据。** 取不到就写"**暂无可靠数据**"。
- 关键事实、重要数据、公司新闻、财报数字、宏观数据**都要注明来源**。
- 数据冲突 → 说明来源差异,采用更权威/更实时的。
- 市场宽度类指标(高于均线比例、新高新低、A/D)最容易取不到——
  **宁可留空标注,也不要用"大约""估计"糊过去**。

### Step 3 — 逐节填写并判断

骨架里每张表下面都有"**请判断**"提示。**填表只是一半工作,判断才是价值所在。**
逐节要点如下。

## 各节判断要点

### §0 今日一句话总结
3-5 句覆盖:涨跌/震荡 → 驱动因素(宏观 / 财报 / 利率 / 地缘 / 油价 / 美元 / 板块轮动)
→ risk-on 还是 risk-off → 宽度改善还是恶化 → 今天最值得关注的一条线索。
结尾一句状态判断(格式示例:`指数强、宽度弱,X 继续主导,但短线拥挤度上升。`)。

### §1 大盘表现总览
指数清单来自 `config/watchlist.toml` 的 `[[report.indices]]`。
判断:是否创历史/阶段新高、是否跌破关键均线;大盘 vs 小盘;成长 vs 价值;
**VIX 方向是否说明避险升温**。

### §2 盘中走势复盘
时间线复盘:盘前 → 开盘形态(高开低走/低开高走/震荡)→ 午盘是否选方向 →
尾盘拉升或跳水 → 盘后财报/新闻导致的异动。
明确判定:是 **sell the news / buy the dip / short squeeze / rotation** 中的哪一种?

### §3 宏观环境
- **3.1 美债收益率**:10Y 是否接近关键压力位(4.5/4.6/4.7%);长端上行是否压制科技股估值;
  曲线陡峭化还是扁平化;债市在交易通胀、赤字、降息预期还是避险。
- **3.2 Fed 降息预期**:CME FedWatch 下次 FOMC 概率、年内预期次数、与前一日的变化、官员讲话。
  按 `_strategy.md` 里你对事件类催化的处理规则判断。
- **3.3 美元/黄金/原油/加密**:美元走强是否压制风险资产;黄金涨是避险还是实际利率下降;
  油价涨是否加通胀压力;加密是否体现风险偏好变化。
- **3.4 当日经济数据**:每项写 数据 / 实际 / 预期 / 前值 / 市场解读。

### §4 板块表现
板块清单来自 `[[report.sectors]]`。判断:最强/最弱;成长 vs 价值;周期 vs 防御;
是否高切低;**资金在板块之间怎么移动**(具体从哪流到哪,不要只说"有轮动")。

### §5 主题与风格
主题清单来自 `[[report.themes]]` —— **那是你自己定义的研究切面**,本仓库不预设。
判断:哪些主题在领先/落后;小盘是否参与;**等权是否跑赢市值加权**;
是扩散行情还是少数权重股拉指数。

### §6 市场宽度与参与度 ★ 最重要的一节
- **6.1 均线参与度**:20 日是否短线过热/恐慌;50 日是否 >50%;100/200 日说明中期趋势是否健康;
  **是否出现"指数创新高、参与度下降"的背离**。
- **6.2 涨跌家数、新高新低**:普涨还是结构性上涨;科技股内部是否健康;新低是否异常增加。
- **6.3 其他内部指标**:A/D Line、McClellan、Put/Call、VIX term structure、VVIX、MOVE、
  高收益与投资级信用利差、成交量是否放大、涨跌成交量比。
  → 若这些指标触及你在 `_strategy.md` 里定义的风险信号组合,必须在 §14/§15 明确点出。

### §7 技术面分析
标的清单来自 `report.technicals`。判断:是否远离关键均线;是否超买超卖;
是否放量滞涨;是否假突破风险;哪些支撑不能破;哪些压力破了会打开空间;
明日继续涨的确认信号 / 回调的风险位。
关键位的**可判定性**见 `modes/_mechanics.md` §6;设在哪里是你的策略。

### §8 重点个股新闻与异动
分组来自 `config/watchlist.toml` 的 `[[groups]]`,顺序与 §12 一致。
判断:各组内部是齐涨齐跌还是严重分化;谁在拉指数、谁在拖累;
是否有监管 / 财报 / 产品 / 反垄断 / 评级 / 目标价新闻。

### §9 财报日历与解读
已公布的:收入与 EPS 是否 beat;毛利率/运营利润率/**自由现金流**变化;
RPO/ARR/订单/backlog/云收入/AI 收入亮点;指引强弱;**股价反应与财报质量是否一致**。

> ★ **headline EPS 可能被一次性项目严重扭曲。** 拆开看经营性利润、自由现金流、资本开支再下结论。

未来 1-3 日的:标记出**持仓标的的 blackout 起始时间**(按 `catalyst.blackout_hours`),
这是次日交易计划的硬约束。

### §10 机构观点与资金流
大行策略观点、指数目标位调整、板块观点变化、评级上调下调、ETF 资金流、期权异动、
大宗交易/内部人交易/回购公告。

### §11 板块轮动判断
用你在 `modes/_strategy.md` §8 定义的市场阶段标签之一。回答:资金主要流入/流出哪里;
你的主线(`config/watchlist.toml` 的 `main_theme`)是否健康;小盘是否参与;
防御板块是否异动;**当前更像趋势延续,还是阶段性顶部震荡**。

### §12 我的重点关注股观察
清单来自 `config/watchlist.toml`(不要在本文件里硬编码)。
每只输出:当日涨跌 / 当前趋势 / 关键新闻 / 支撑 / 压力 / 判断。
判断**必须用你在 `modes/_strategy.md` §8 定义的关注股状态标签之一**。

### §13 明日交易计划 / 观察清单
宏观观察 → 大盘观察(`report.watch_levels`)→ 板块观察 → 个股观察(每只写原因)。
**这一节要和 `modes/premarket.md` 的候选清单格式对齐**,让次日盘前能直接接手:
每个候选写清 方向 / 理由 / 触发参考 / 准入判定(按 `_strategy.md`)。

### §14 风险提示
维度来自 `report.risk_dimensions` —— **按你实际承担的风险定义**,不是照抄别人的。
逐维度评级(低 / 中 / 中高 / 高)。每个维度必须能被**当天的数据**判定。

### §15 最终结论
- **今日市场结论**:3-5 句。
- **当前市场阶段**:选一个标签。
- **我的操作倾向**(中性语言,不构成投资建议):是否适合追高 / 逢低 / 等财报 /
  控仓位;哪些板块值得关注、哪些需谨慎。
- **最值得关注的 5 个信号**。
